# AEGIS Product Surface

Dashboard: fleet health, incident KPIs, threat confidence, event rate.

Live Investigation: agent-by-agent execution stream, incident timeline, decision trace.

Incidents: searchable incident list and drill-down.

Hosts: synthetic endpoint inventory with isolate/restore controls.

Threat Intel: synthetic IOC feed.

Attack Simulation: controlled scenarios for demonstrations and regression tests.

Agents: status, role, accuracy and latency.

Evidence Graph: source relationships extracted from incident telemetry.

Reports: generated incident report for each incident.

Policies: enable/disable deterministic authorization rules.

Settings: organization/theme/refresh settings.
